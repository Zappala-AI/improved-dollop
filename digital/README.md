# Panel digital de ZAVIAN

Abrí `index.html` directamente en el navegador. No necesita instalación ni internet para funcionar después de abrirlo.

Incluye:

- Catálogo inicial de productos.
- Proveedores de San Juan con fuentes y estados de verificación.
- Textos de publicaciones.
- Tres oportunidades de negocio.
- Registro de ventas con cálculo automático de total y ganancia.
- Seguimiento de contactos.
- En cada contacto podés editar respuesta real, catálogo recibido, precio/mínimo y autorización de fotos.
- Los contactos con datos públicos muestran accesos directos a WhatsApp y/o email; abrirlos no envía nada automáticamente.
- El panel permite exportar e importar un respaldo JSON para mover los datos a otro dispositivo.

Los datos que agregues se guardan en el almacenamiento local del navegador. Si borrás los datos del sitio o cambiás de dispositivo, deberás volver a cargarlos.
